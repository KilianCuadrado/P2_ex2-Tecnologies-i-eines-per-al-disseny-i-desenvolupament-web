  
**`Exercici 2 – Ampliació avançada de la plantilla web`**

## **`Objectiu`**

`Ampliar la plantilla web desenvolupada anteriorment per convertir-la en una pàgina moderna, adaptable a diferents dispositius i amb elements interactius.`

### **`Repte 1. Disseny responsive`** `Adapta la pàgina perquè es visualitzi correctament en diferents dispositius utilitzant els breakpoints de Tailwind CSS.`

* **`Mòbil:`** `els elements es mostren en una sola columna.`  
* **`Tauleta (md:):`** `els continguts es distribueixen en dues columnes.`  
* **`Ordinador (lg:):`** `els continguts es distribueixen en tres columnes.`

`Utilitza grid, flex, gap, md: i lg:.`

### **`Repte 2. Secció de targetes`**

`Afegeix una secció amb un mínim de 6 targetes que representin productes, serveis o projectes.`

`Cada targeta ha de contenir:`

* `Una imatge.`  
* `Un títol i una descripció.`  
* `Un botó per obtenir més informació.`  
* `Efectes visuals quan el cursor passa per sobre (hover:).`  
* `Cantonades arrodonides (rounded-*) i ombres (shadow-*).`

`Les targetes han d'adaptar-se automàticament a la mida de la pantalla.`

### **`Repte 3. Mode fosc (Dark Mode)`**

`Implementa un botó que permeti canviar entre el mode clar i el mode fosc.`

`Requisits:`

* `Utilitza les variants dark: de Tailwind CSS.`  
* `El canvi ha d'afectar el fons, els textos, les targetes i la navegació.`  
* `Guarda la preferència de l'usuari amb localStorage perquè es mantingui quan es recarregui la pàgina.`

### **`Repte 4. Formulari de contacte`**

`Afegeix un formulari amb els camps següents:`

* `Nom.`  
* `Correu electrònic.`  
* `Assumpte.`  
* `Missatge.`  
* `Botó d'enviament.`

`Utilitza Tailwind CSS per estilitzar-lo, incloent-hi els estats focus: i invalid:.`

`Implementa una validació amb JavaScript que comprovi que els camps obligatoris estiguin emplenats i que el correu tingui un format correcte.`

`No és necessari implementar un servidor ni enviar realment el formulari.`

## **`Repte extra opcional: components reutilitzables`**

`Investiga com evitar repetir el mateix codi HTML quan diverses targetes comparteixen el mateix disseny.`

`Crea un array d'objectes en JavaScript amb les dades de les targetes i genera-les dinàmicament amb JavaScript.`

## **`Lliurament`**

`Entrega el projecte complet amb els fitxers HTML i CSS necessaris.`

`La pàgina ha de funcionar correctament tant en dispositius mòbils com en ordinadors.`
